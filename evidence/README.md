# Evidence

This directory contains manifests, hashes, normalized records, traceability, contradictions, and measurements derived from immutable supplied evidence.

Do not place raw uploaded archives, recordings, or original `.rbxlx`/`.rbxl` files in ordinary Git history.

Source priority:
1. Newly supplied original `.rbxlx` serialized data
2. Original scripts/data embedded in those files
3. Newly supplied RemoteSpy captures
4. Existing recovered original TWR scripts
5. Original gameplay recordings
6. Original screenshots/images
7. Existing compiled/reference documentation
8. Previous TestPlace reconstruction
9. Strong inference
10. Temporary approximation

Every recovered/generated artifact should record provenance or uncertainty. Static place parsing must never execute embedded scripts.
