## Pass117 physical collision cache

The matching owner-private `TWR COL26 v1` cache is generated by projecting **every source-authored collidable component**, including invisible source server walls, through the existing Godot Roblox-CFrame coordinate reflection and scale 0.28m per Roblox stud. Oriented Part boxes emit 12 triangles; original WedgePart wedge primitives emit 8 triangles using `RobloxPrimitiveGeometry.WedgeCorners` and wedge topology. Source MeshPart/UnionOperation collision uses author-oriented **bounding-box proxies**, not original custom triangles, which are not embedded in the XML.

### Installing into an existing offline Windows executable

Extract the ZIP's **Content** folder into the folder containing `ThoseWhoRemainOffline.exe`. The game's existing `LaboratorySourceLoader.TryBuild` automatically **prefers the owner-original Laboratory** over the Pass115/116 approximate fallback. The map loader preserves the original positions and uses prepared custom mesh/texture resources when installed, otherwise uses visual shape approximations for unavailable art.

Or use the GitHub-tracked strict installer:

```powershell
python tools/maps/install_private_laboratory117.py --private-pack "TWR-Pass117-Original-Laboratory-Private-Source.zip" --game-folder "C:\Games\ThoseWhoRemainOffline"
```

The installer validates both full file SHA-256 digests, reads every scene record, checks source markers and cache tile/triangle totals, and **backs up existing scene/cache binaries** before updating. It refuses any synthetic substitute and refuses to install unless a built Windows executable exists.

For a new owner-private executable package, `build/Windows/package_private.ps1` now accepts **both** the original authenticated `twr-source-map-v2` Laboratory scene under `-LaboratoryPack` and its matched `-LaboratoryCollision`. The legacy Lab v1 pack option and complete private ten-map ZIP remain supported. Owner-original data still cannot be packaged inside public repository output.
