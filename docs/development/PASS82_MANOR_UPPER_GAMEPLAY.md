# Pass 82 - Fallback Manor second-floor pickups and objectives

Building on passes 79-81, the three reconstructed upper-floor balcony pairs
now supply three distinct higher-floor pickup markers and three objective
markers. Positions derive directly from the previously physically accepted
stair UpperFeet points; the E-key loot and objective command runtime is
unchanged, including existing vertical-distance and wall line-of-sight gates.

Natural pickups choose from the expanded marker pool. Starting in Wave 3,
the fallback Manor Regular objective cycle includes upstairs rooms; early
waves preserve existing lower-floor placements. All nine other maps and any
owner-original source maps keep their original item/objective logic untouched.

These are newly authored, approximate gameplay marker locations, not original
Roblox marker transforms. Pass83 tests actual Godot-floor support, stair/upper
access and no through-floor pickup collection in native Windows.
